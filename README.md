# Research Portfolio Website

A lightweight static portfolio for showcasing research work, publications, technical skills, and collaboration details.

## Files

- `index.html`: Page content and structure.
- `styles.css`: Responsive visual design.
- `assets/research-hero.png`: Generated hero image used on the first screen.

## Customize

1. Replace `Your Name`, `YN`, and `your.email@example.com`.
2. Update the research areas, project descriptions, publications, and skills.
3. Replace `#` links with your CV, GitHub, Google Scholar, LinkedIn, ORCID, or lab profile URLs.
4. Update the page title and meta description in `index.html`.

You can open `index.html` directly in a browser. No build step is required.
